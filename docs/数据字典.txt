电商平台客户购买行为与转化分析
数据字典 / Data Dictionary

一、数据概况
-----------
数据名称：Customer Purchase Behavior Dataset (E-commerce)
数据来源：Kaggle（作者/发布者：Gautham Vijayaraj）
数据规模：500,000 行 × 18 列
文件格式：CSV，逗号分隔，UTF-8，首行为表头
许可：CC BY-NC 4.0（署名—禁止商用）
说明：本仓库只提供前 5,000 行样例，完整数据请从 Kaggle 下载。

二、字段说明
-----------
1. Customer_ID
   类型：string
   说明：客户唯一标识
   示例：ID,001

2. Age
   类型：integer
   说明：客户年龄（岁）
   范围：15–81

3. AnnualIncome
   类型：float
   说明：客户年收入（美元）
   范围：约 11,966–204,178

4. NumberOfPurchases
   类型：integer
   说明：客户总购买次数
   范围：非负整数

5. TimeSpentOnWebsite
   类型：float
   说明：每次访问网站的平均停留时长（分钟）
   范围：非负

6. CustomerTenureYears
   类型：float
   说明：客户加入平台的时长（年）
   范围：非负

7. LastPurchaseDaysAgo
   类型：integer
   说明：距离客户最近一次购买的天数
   范围：非负整数

8. Gender
   类型：category
   说明：客户性别
   取值：Male / Female

9. ProductCategory
   类型：category
   说明：客户最常购买的产品类别
   取值：Fashion / Kitchen / Electronics / Furniture / Groceries

10. PreferredDevice
    类型：category
    说明：客户最常使用的设备
    取值：Mobile / Desktop / Tablet

11. Region
    类型：category
    说明：客户所在区域
    取值：North / South / East / West

12. ReferralSource
    类型：category
    说明：客户发现平台的途径
    取值：Organic / Paid Ads / Email / Social / Referral

13. CustomerSegment
    类型：category
    说明：企业定义的客户分类
    取值：Regular / Premium / VIP

14. LoyaltyProgram
    类型：binary
    说明：客户是否加入忠诚度计划
    取值：0 / 1

15. DiscountsAvailed
    类型：integer
    说明：客户使用的折扣券/优惠券数量
    范围：非负整数

16. SessionCount
    类型：integer
    说明：记录的客户会话/访问次数
    范围：非负整数

17. CustomerSatisfaction
    类型：integer
    说明：客户满意度评分
    取值：1–5（1 = 非常不满意，5 = 非常满意）

18. PurchaseStatus
    类型：binary
    说明：购买是否成功（目标变量）
    取值：0 = 未购买，1 = 购买

三、工作簿计算字段
-----------------
1. 转化率
   SUM(IF [PurchaseStatus] = 1 THEN 1 ELSE 0 END) / COUNT([PurchaseStatus])

2. 年龄分组
   IF [Age] < 25 THEN '18-24岁'
   ELSEIF [Age] < 35 THEN '25-34岁'
   ELSEIF [Age] < 45 THEN '35-44岁'
   ELSEIF [Age] < 55 THEN '45-54岁'
   ELSE '55岁及以上'
   END

3. 年收入分组
   IF [AnnualIncome] < 40000 THEN '低收入(<4万)'
   ELSEIF [AnnualIncome] < 70000 THEN '中低收入(4-7万)'
   ELSEIF [AnnualIncome] < 100000 THEN '中等收入(7-10万)'
   ELSEIF [AnnualIncome] < 150000 THEN '中高收入(10-15万)'
   ELSE '高收入(>15万)'
   END

4. 网站停留时长分组
   IF [TimeSpentOnWebsite] < 3 THEN '短停留(<3分钟)'
   ELSEIF [TimeSpentOnWebsite] < 8 THEN '中停留(3-8分钟)'
   ELSE '长停留(>8分钟)'
   END

5. 连续停留时间数据桶
   FLOOR([TimeSpentOnWebsite] / 3) * 3
